Ravomi 正在构建一个无限画布工作空间，让人把研究、代码、素材与任务，同负责它们的 Agent 组织在一起。看清整个项目，同时让不同工作分支并行推进。


**可见。** 查看每个 Agent 的任务、进度、依赖与成果。


**可连接。** 从目标拆解计划，连接可复用模块，追踪 Agent 之间的任务与上下文交接。


**可干预。** 审阅结果、调整计划、暂停工作并指导下一步，始终保持对工作进程的掌握。

### 当前进展


Ravomi 处于早期原型阶段。当前仓库以本地画布编辑器为基础；AI 执行、工作流编排与多 Agent 交接仍在规划中。产品与设计文档明确区分现有能力和待探索方向。


我们希望工作空间在任务增多时仍然清晰：素净的界面、易读的连接关系，以及一只带有克制雾蓝紫柔光的石墨黑团子猫。


关注[项目仓库](https://github.com/Ravomi/ravomi-app)，了解实现进展、设计决策与已知限制。
